# RentCalc — PWA-підготовка

Це перший крок до встановлюваної вебверсії RentCalc.

Файли:
- `index.html` — застосунок
- `manifest.json` — назва, іконка та режим запуску
- `service-worker.js` — кешування для повторного запуску/офлайну
- `icon.svg` — іконка

## Як перевірити
PWA-функції працюють лише коли сайт відкрито через HTTPS або localhost. Відкриття `index.html` прямо з файлового менеджера не активує встановлення PWA.

Для тесту потрібно розмістити ці файли на HTTPS-хостингу (наприклад, GitHub Pages або Netlify), відкрити посилання у Chrome на Android і скористатися меню браузера → «Установити застосунок» / «Додати на головний екран».

## Важливо
Це ще не готовий пакет Google Play (AAB). Для публікації потрібні додаткове пакування, тестування та виконання актуальних вимог Google Play.
